# 🪙 六爻铜钱起卦工具

纯前端铜钱摇卦工具，模拟传统三枚铜钱六次起卦，自动生成本卦、变卦与动爻信息，一键复制卦象给 AI 解读。

在线地址: https://liuyao-gua.pages.dev

## 主要功能

- **双起卦模式**：电子模拟抛铜钱 / 手动真实摇卦录入，满足不同使用习惯
- **3D 铜钱抛洒动画**：还原传统摇卦视觉效果，沉浸式起卦体验
- **自动演算八卦**：本卦、变卦、动爻位置完整展示，无需手动排卦
- **爻象可视化区分**：少阳 / 少阴 / 老阳 / 老阴，动爻高亮标记，一目了然
- **一键复制完整卦文**：自带 AI 解读提示词模板，可直接粘贴给 ChatGPT、DeepSeek、Claude 等 AI 平台解读
- **本地历史记录**：自动缓存最近 30 条起卦记录，支持恢复、单条删除、清空全部
- **无后端、无广告**：所有数据仅保存在浏览器本地，隐私安全

## 技术栈

- Vanilla JavaScript（纯原生 JS，零第三方依赖）
- 原生 CSS3（3D 翻转动画、响应式布局）
- Cloudflare Pages（部署托管）

## 本地运行

本项目为纯静态 HTML 项目，无需安装依赖、无需构建命令。克隆后直接用浏览器打开 `index.html` 即可。

## 使用流程

1. 选择起卦模式（电子摇卦 / 手动录入）
2. 进行六次摇卦，记录每次结果
3. 系统自动演算本卦、变卦与动爻
4. 查看卦象详情，动爻高亮显示
5. 一键复制卦文 + AI 提示词模板
6. 粘贴到 AI 平台获取解读
